# Gitful for GNOME: contributor handoff

This directory is for the GNOME Shell extension. The shared Python CLI is in `gitful_core/`; its interface is documented in [the client contract](../docs/client-contract.md). The Omarchy client remains at the repository root. The first milestone is a panel indicator that shows the tracked repositories, current branch, dirty state, and incoming count from `gitful status`. Add a manual refresh and a clear missing-helper message. Build the menu and preferences incrementally after that vertical slice works.

Use GJS for the extension. Run `gitful` asynchronously with `Gio.Subprocess` and parse its JSON result after it exits. Do not block GNOME Shell during Git or network operations. Remove timers, signals, and pending work in `disable()`. A later preferences window can use GTK/Adwaita in `prefs.js`; Shell UI code belongs in `extension.js`. The GNOME [getting started guide](https://gjs.guide/extensions/development/creating.html) and [debugging guide](https://gjs.guide/extensions/development/debugging.html) cover the extension skeleton and nested-shell testing.

The first development setup is: install the shared CLI with `pipx install .` from the repository, verify `gitful status`, then develop the extension in this directory. The extension should explain the missing CLI dependency instead of installing packages itself. Before investing in the full UI, validate the distribution route with GNOME reviewers. Their [review guidelines](https://gjs.guide/extensions/review-guidelines/review-guidelines.html#scripts-and-binaries) strongly discourage external scripts and generally require extension scripts to be GJS. Acceptance of an extension that invokes this separately installed Python helper is not guaranteed. If that route is unsuitable, the documented command semantics and tests remain the reference for a native GJS implementation.

Please keep GNOME-specific code and packaging here. Changes to the shared CLI contract should include a contract test and an update to `docs/client-contract.md`. Do not copy Omarchy's QML into the extension: GNOME Shell uses its own GJS UI APIs.
